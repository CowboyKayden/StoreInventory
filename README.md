# This is a practice Inventory Management System

# This is a Python-based inventory management system that allows users to store and manage product information using a HashMap (Python dictionary).

# The program allows users to add, search, update, and remove products from the inventory. Each product contains information such as name, quantity, price, category, and UPC.
# I am constantly updating and adding functions to this project, it is a practice environment that you can watch me learn new data strucutres and algorithms

## StoreInventory 0.4 – Function Refactoring and Menu Improvements

In version 0.4, I refactored the inventory management functions to improve code organization, reusability, and functionality. Functions such as searching, adding, deleting, editing, and locating products now accept specific parameters and return values instead of handling all user interaction internally. I also added inventory analysis functions to calculate total inventory quantity, count low stock products, and identify the highest and lowest stock products. The menu was updated to handle user input, display returned results, and manage empty inventory or unsuccessful searches. Additionally, I implemented data type conversions for quantity and price when editing products and added a main execution guard to control program startup.
